# Lucide reply icons

The reply-icon catalogue (`catalog.json`) and glyphs (`glyphs.json`) were
generated from the official Lucide repository at commit [`2bfb9bb1bae5d74f6a9f81640ddd8bccc2c71860`](https://github.com/lucide-icons/lucide/commit/2bfb9bb1bae5d74f6a9f81640ddd8bccc2c71860).
Lucide is ISC licensed; keep `LUCIDE-LICENSE.txt` with these files. The
generator is not part of this repository, so edit or regenerate these JSON files
from that Lucide commit and keep the catalogue order stable.

The UI bundles the trusted SVG glyphs with JavaScript so icons render even when
scripts and images are hosted on a separate CDN origin. Model output only selects
an allowed icon name; it never supplies SVG markup.
